# 术语科普模板（以 Transformer 为例）

> 用途：学习模式"开讲前先过术语表"的示范（模式一·步骤4）。老师照着讲，**不赌用户预习过**。
> 原则：直觉先行——先讲"这个模块在干嘛"，再逐个定义符号，最后才允许上公式。

## 讲法（每模块一遍）

1. **一句话直觉**：不用术语，讲清"这个模块解决什么问题、在干嘛"（类比/日常语言）。
2. **逐个术语**：本模块每个新符号按"是什么 + 为什么需要"两句话讲，配生活化类比。
3. **公式/计算**：公式出现时，其中每个符号在前面都已定义；出现没定义的新符号就停下补定义。

## 处理规则

- 用户预习过术语表 → 只做确认/答疑，不重复通读；没预习 → 老师逐条通读（默认按没预习处理）。
- 半路冒出的新术语 → 就地补定义（是什么 + 为什么需要），并回写术语表。

## 示例：模块 2 Self-Attention 的术语科普讲稿

### 一句话直觉

让每个词去全场所有词那里"借信息"，借多少按相关度来——相关度高的多拿，低的少拿。

### 逐个术语（是什么 + 为什么需要 + 类比）

| 术语 | 是什么 | 为什么需要 | 类比 |
|---|---|---|---|
| Q (Query) | 每个词投影出的"查询向量"，表达"我在找什么" | 让每个词能向全场发问 | 你要发的搜索条件 |
| K (Key) | 每个词投影出的"键向量"，表达"我是谁" | 让别人能认出"你是什么" | 别人的 ID / 索引列 |
| V (Value) | 每个词投影出的"值向量"，表达"我能提供什么" | 真正要被取走的信息 | 命中的 value 字段 |
| W_Q / W_K / W_V | 三个可学习矩阵，把输入 X 分别投影成 Q/K/V | 一份 X 要干三件不同的活 | 三套模具 |
| 注意力分数 | Q 和每个 K 做点积 | 判断"这个词对我多重要" | 匹配度打分 |
| ÷√d_k | 除以维度 d_k 的平方根 | 防分数太大、softmax 变"硬"、梯度消失 | 温度调节 |
| softmax | 把分数压成 0~1 且和为 1 的分布 | 让注意力变成加权平均 | 占比 |
| 加权求和 | 按权重把全场 V 混合 | 得到每个词的新向量 | 按占比合成资料 |

### 公式（此时符号已全部定义）

`Attention(Q,K,V) = softmax( Q·Kᵀ / √d_k ) · V`
