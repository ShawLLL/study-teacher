# 学习偏好表单（摸底用）

> 用途：学习模式·步骤1 摸底时，问清楚用户的学习偏好，一对一贴合需求。
> 用法：把选项念给用户选（或让用户自行填）；答案记入该知识点 README"已有基础 / 学习偏好"，后续教学按此执行，不满意随时调。

## 问题

### 1. 呈现方式——你更想怎么被讲？

- **数形结合**：图形 / 坐标轴 / 动画伴随公式一起上（例：学 transform 时画坐标系看矩阵怎么变换，学数据结构时看链表/树怎么动）
- **纯理论**：文字 + 公式推导，干净利落
- **混合**：先用图建立直觉，再上公式

### 2. 直观模型——原理性知识点，要不要可动手的模拟/数字模型？

（这类知识：数据结构、transform、物理加速度、注意力机制……抽象、看不见）
- **必须**：每次碰到抽象概念，都要一个小模拟/数值例子能亲手调参数看变化
- **看情况**：卡住或觉得抽象时再上
- **不需要**：文字/公式能讲清楚就行

### 3. 直觉建立方式——开讲一个新概念时，先给什么？

- **类比先行**：先用生活化/已有领域类比建立直觉，再贴定义
- **直给定义**：直接给定义/公式，类比只是补充

## 记录格式（写入该知识点 README"已有基础 / 学习偏好"）

```
学习偏好（<日期>）：
- 呈现方式：数形结合 / 纯理论 / 混合
- 模拟模型：必须 / 看情况 / 不需要
- 直觉建立：类比先行 / 直给定义
```

## 注意

- 表单答案针对"这个知识点"填，不是一次定终身；用户中途说"换个方式"立即改。
- 偏好和"教学顺序红线（直觉→角色→公式）"是两回事：红线管顺序，偏好管呈现媒介。
